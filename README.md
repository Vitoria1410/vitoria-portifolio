## 🛠️ Tecnologias & Arquitetura

- **Frontend 100% Autocontido:** HTML5 semântico, CSS3 moderno e JavaScript puro (ES6+), sem dependência de frameworks ou bibliotecas externas pesadas.
- **HTML5 Canvas & Efeitos Visuais:** Múltiplas camadas de canvas para pintura interativa, sistemas de partículas e lousa de desenho do visitante.
- **Design Responsivo & Mobile First:** Experiência pensada tanto para desktop quanto para toque em dispositivos móveis.
- **Acessibilidade & Inclusão:** Suporte completo à diretiva `@media (prefers-reduced-motion: reduce)`, controles de pausar animações, diálogos acessíveis com `<dialog>` e foco gerenciado.
- **Modo Escuro / Claro:** Alternância de tema integrada com persistência visual.
